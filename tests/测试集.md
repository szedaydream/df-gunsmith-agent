# 改枪 Agent 手工测试集（18 题）

每次改动 prompt 或代码后，把这 18 题跑一遍，对照「验收标准」打勾。
任何一项回退（以前对现在错）都要停下来查原因。

## A. 澄清能力（意图判断 → clarify）

| # | 输入 | 验收标准 |
|---|------|---------|
| A1 | 帮我改把 M4A1 | 反问模式和交战距离，不给完整方案 |
| A2 | 有什么枪推荐吗 | 反问或给方向性建议，不直接丢方案 |
| A3 | 给我整把狙击枪 | 反问模式/距离或预算，不给完整方案 |

## B. 方案生成（意图判断 → answer + 搜索）

| # | 输入 | 验收标准 |
|---|------|---------|
| B1 | 帮我改把 M4A1，全面战场打中远距离 | 输出完整方案卡：枪械/定位/六格配件/使用建议 |
| B2 | AKM 烽火地带近战怎么配 | 输出方案卡，定位体现「烽火地带+近战」 |
| B3 | AWM 全面战场打远点 | 输出方案卡，配件取向偏稳定和射程 |
| B4 | 预算有限，MP5 烽火地带近战 | 方案卡 + 配件偏性价比取向 |

## C. 防幻觉与标注

| # | 输入 | 验收标准 |
|---|------|---------|
| C1 | （搜索关闭时）M4A1 全面战场中远 | 开头有「未经最新资料核实」声明 |
| C2 | （搜索开启时）同上 | 资料外补充的配件带「（未核实）」标注 |
| C3 | 有没有「雷神之锤」这个枪口 | 不承认不存在的配件；不确定就明说 |

## D. 问答与对比（非方案类）

| # | 输入 | 验收标准 |
|---|------|---------|
| D1 | M4A1 和 AKM 哪个适合新手 | 给出对比分析，不强行套方案卡格式 |
| D2 | 枪口补偿器和消音器有什么区别 | 清楚解释差异和适用场景 |

## E. 闲聊与边界

| # | 输入 | 验收标准 |
|---|------|---------|
| E1 | 你好 / 谢谢 | 友好回应，不触发搜索，不丢方案卡 |
| E2 | 今天天气怎么样 | 礼貌说明自己是改枪顾问，引导回主题 |

## F. 武器特性与定制化（2026-08-09 新增）

| # | 输入 | 验收标准 |
|---|------|---------|
| F1 | MK47 怎么改？全面战场中距离 | 方案围绕「1.25 倍真实后坐力收益」展开，配件理由体现服务特性；【属性评估】指出过高/过低项 |
| F2 | 腾龙这枪改装要注意什么 | 提到「着重堆开火稳定性」的特性（知识库命中） |
| F3 | SVCH 我想装 5 倍镜打远点，全面战场 | 尊重用户的 5 倍镜选择（不强行改回红点），围绕它平衡其他槽位；【属性评估】指出开镜速度等红线问题并问能否接受 |

## G. 搜索与上下文管理（2026-08-09 二更）

| # | 输入 | 验收标准 |
|---|------|---------|
| G1 | K416 烽火地带中近距离怎么改（kimi_builtin 模式） | 先触发联网搜索再作答；配件不标（未核实）；开头无「未经核实」声明 |
| G2 | 连续聊 15 条以上后换个新枪问 | 新回答不受早前话题干扰（旧消息已被压缩为前情提要） |
| G3 | 点「清空对话」后再提问 | 聊天区清空；新回答不记得清空前聊过的内容 |
| G4 | K437 烽火地带中近距离怎么改 | 九槽位齐全（含后握把/护木片/镭射）；每条配件带来源标注（聪聪/NGA/未核实/推理等） |
